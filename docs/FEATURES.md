# GroupGuard 2.0.0 功能与实现边界

GroupGuard 是一个由 TRSS 加载、经 NapCat OneBot v11 操作 QQ 的独立插件。A—H 能力都在本插件中；统计、新闻和点赞是内部辅助功能，不需要另装插件。插件内置本机浏览器配置服务，页面关闭不影响群管运行。具体安装、指令和配置见 [README](../README.md)。

下表用于定位功能和检查入口，测试文件存在不等于本轮已经执行或全部通过。实际执行结果按 [验证范围](VERIFICATION.md) 区分本地模拟和真实平台。

## 指令和配置的统一范围

- 有前缀的正式入口只用半角 `#群管…`、`/群管…`；帮助必须明确发送“群管帮助”，可后接“文字”。
- 保留禁言/解禁的裸词及半角简写；裸“撤回”须有效群引用，裸“赞我”须整条正文精确匹配。
- 移除所有群卫别名、全角前缀、裸群管帮助、确认加群/拒绝加群兼容入口、旧发言日榜/月榜和所有带前缀点赞。
- 移除离群自动拉黑和定时全体禁言/解禁；现有名单、手动管理操作和其他保留的调度不删除。
- 默认所有群关闭；邀请审核、欢迎、离群通知、新闻定时、自动退群、点赞默认关闭。统计和撤回默认开，但受本群总开关约束。
- 普通命令识别 `isMaster || masters`；自动退群主人豁免只读取手动配置的 `masters`，不自动导入 TRSS 主人列表。

## 浏览器配置与外部验证边界

浏览器配置由插件内置服务提供，默认 `127.0.0.1:15083`。首次登录强制修改初始密码；改密后所有旧会话退出。界面零 npm 依赖、无 CDN，只使用同源静态资源。密码和 Key 不持久到浏览器本地存储；API 通过 HttpOnly 会话和 CSRF 校验保护，保存需当前配置 revision，发生冲突或写入结果未知时先重载，不自动重复覆盖。

单次管理 JSON 请求上限为 1 MiB，覆盖合法大名单的整份表单保存；每个字段仍独立遵守名单项数、文本长度和数值范围校验。

本群表单覆盖保留的开关、审核、名单、通知和定时字段；全局表单覆盖邀请、通知、队列、群名单、自动退群和时区。新闻按精确账号/群分别设置 URL 与鉴权，Key 只回读 `hasKey`，保留/替换/清空分开；切换对象加载其完整来源，新对象清空接口和鉴权，提交前再次核对绑定。主人只显示已配置与否，不能在浏览器更换。

真实新闻来源的鉴权/返回格式、真实 TRSS/NapCat 加载与 QQ 收图、真实 GitHub 网络更新需要对应环境验证。本地模拟与隔离 Git 仓库检查不证明这些外部能力已经验收。

不提供旧独立 OneBot HTTP 启动、事件接收端口或健康检查服务；新增配置 HTTP 服务只负责受登录保护的管理操作，不接收 OneBot 事件。Docker 仅宿主回环映射，远程通过 SSH 本机隧道访问。帮助制作可借 TRSS 渲染器；普通安装直接使用随包 JPEG，不要求模型或渲染环境。离线演示脚本只生成本地 HTML，不监听端口，不连接 QQ。

历史版本的独立服务检查、旧指令或服务器记录仅属于历史结果，不能作为 2.0.0 的验证证据。
