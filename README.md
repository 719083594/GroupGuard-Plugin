# GroupGuard · 群管

给 QQ 机器人用的群管理插件。日常的禁言、踢人、撤回消息、入群审核都能处理，也带入群欢迎、发言榜、每日新闻和点赞。常用设置可以在 QQ 里修改，新闻来源和详细配置可以打开网页调整。

目前适配 **TRSS-Yunzai**，已提供通用框架接入接口，其他框架以后按需补充。

## 安装

先准备好能正常收发消息的 TRSS-Yunzai。当前适配使用 NapCat，群管需要 Node.js 20 或更新版本。

### 使用安装向导

在 Linux 服务器的**宿主机终端**运行：

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/719083594/GroupGuard-Plugin/main/scripts/install.sh)
```

宿主机需要 Git、curl、Python 3.9+；Docker 安装还需要 Docker Compose。向导会寻找现有 TRSS、安装插件并配置网页入口，期间机器人会短暂重启。有多个机器人或使用自定义目录时，可以指定路径：

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/719083594/GroupGuard-Plugin/main/scripts/install.sh) --trss /实际/TRSS目录
```

### 手动安装

在 TRSS 根目录执行：

```sh
git clone https://github.com/719083594/GroupGuard-Plugin.git plugins/GroupGuard-Plugin
```

重启机器人后，插件会生成配置文件。也可以从 [Releases](https://github.com/719083594/GroupGuard-Plugin/releases) 下载 ZIP，解压到相同位置。

Docker 环境需要配置网页入口时，在宿主机的 TRSS 目录运行：

```sh
python3 plugins/GroupGuard-Plugin/scripts/install.py --trss "$PWD"
```

Windows 普通安装、Docker 手动配置、端口选择与故障恢复见 [安装指南](docs/INSTALL.md)。

## 第一次使用

1. 编辑 `plugins/GroupGuard-Plugin/config/local.json`，把已有的 `masters` 改为负责人的 QQ，例如：

   ```json
   "masters": ["123456789"]
   ```

   号码换成自己的，其他配置保留。可以填写多位主人。

2. 由群主或机器人主人在群内发送 `#群管开启`。
3. 发送 `#群管帮助` 查看帮助，`#群管状态` 查看本群配置。

`masters` 是插件主人名单，只在文件中维护。普通命令也认可 TRSS 主人；**自动退群的主人豁免只读取 `masters`**，因此请把实际负责人填进去。机器人执行禁言、踢人等操作，还需要相应的 QQ 群权限。

群管默认在各群关闭，邀请审核默认不接管。按群开启后，再按需要配置审核、欢迎、新闻等功能。

## 网页配置

默认地址：`http://127.0.0.1:15083`。

首次密码在插件的 `data/admin-initial-password.txt` 中。登录后按提示修改密码，新密码至少 12 个字符，再重新登录。网页密码和 QQ 主人名单分别维护。

网页可以调整本群设置、新闻来源、全局设置和账号安全。新闻按机器人、群分别配置 API 与 Key；已有 Key 可以保留、替换或清空。`masters` 仍由文件手动维护。

远程服务器可通过 SSH 隧道访问，把下面的用户名和服务器换成自己的：

```sh
ssh -N -L 36083:127.0.0.1:15083 用户@服务器
```

然后打开 `http://127.0.0.1:36083`。如果安装向导选择了其他端口，以向导输出为准。

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `GROUPGUARD_ADMIN_ENABLED` | 开启 | 设为 `0` 关闭网页服务 |
| `GROUPGUARD_ADMIN_HOST` | `127.0.0.1` | 网页监听地址；Docker 容器内按安装指南设置 |
| `GROUPGUARD_ADMIN_PORT` | `15083` | 网页端口 |

这些环境变量修改后需要重启机器人。平时在网页保存的群设置会即时读取；多人同时修改时，页面会提示重新加载，避免覆盖别人的改动。

## 指令

下表中的 `#群管…` 都可以换成 `/群管…`，参数和权限相同。群内功能在对应群使用，全局设置和更新在主人私聊中使用。

| 功能 | 指令 | 权限与条件 |
|---|---|---|
| 帮助 | `#群管帮助`、`#群管帮助 文字` | 所有人；不要求开启本群 |
| 版本 | `#群管版本` | 所有人；不要求开启本群 |
| 本群开关 | `#群管开启`、`#群管关闭` | 群主或主人 |
| 状态 | `#群管状态`、`#群管状态 文字` | 群管理员、群主或主人；默认 PNG，图片失败退文字，文字后缀直接纯文字 |
| 本群配置 | `#群管设置 <字段> <值>` | 群管理员、群主或主人；本群已开启 |
| 成员黑名单 | `#群管黑名单`；后接 `添加 <QQ>` 或 `删除 <QQ>` | 群管理员、群主或主人 |
| 成员白名单 | `#群管白名单`；后接 `添加 <QQ>` 或 `删除 <QQ>` | 群管理员、群主或主人 |
| 单人禁言 | `#群管禁言 @成员 [时长]` | 群管理员、群主或主人；机器人须管理权限 |
| 单人解禁 | `#群管解禁 @成员` | 同禁言 |
| 踢出成员 | `#群管踢 @成员` | 双方管理权限和目标保护；不永久拒绝再次申请 |
| 全体禁言/解禁 | `#群管全体禁言`、`#群管全体解禁` | 双方相应管理权限 |
| 管理员任免 | `#群管设管理 @成员`、`#群管撤管理 @成员` | 操作人须群主或主人；机器人须群主 |
| 专属头衔 | `#群管头衔 @成员 <头衔>` | 同管理员任免；头衔 1—30 字符 |
| 引用撤回 | 引用后 `#群管撤回`，或引用后裸 `撤回` | 群管理权限、有效本群引用及目标校验 |
| 批量撤回 | `#群管撤回 @成员 [条数]` | 默认 1 条，受条数/历史窗口限制 |
| 发言榜 | `#群管今日榜`、`#群管昨日榜`、`#群管月榜` | 本群开启、`statistics` 开启 |
| 新闻 | `#群管日报` | 本群开启并配置本群来源 |
| QQ 点赞 | 裸 `赞我` | 群内，本群开启、`likes` 开启，额度未满 |
| 待审列表 | `#群管待审核` | 已开启的本群/管理群中，按管理权限和可见范围检查 |
| 审核同意/拒绝 | 引用通知后 `#群管同意` / `#群管拒绝`，或后接 `<请求编号>` | 按请求、通知位置和权限判断；主人、指定私聊审核用户及允许的邀请人按相应范围处理 |
| 全局配置 | `#群管全局 <字段> <值>` | 仅主人私聊 |
| 群黑白名单 | `#群管群黑名单`、`#群管群白名单`；后接 `添加 <群号>` 或 `删除 <群号>` | 仅主人私聊 |
| 维护 | `#群管日志`、`#群管更新日志`、`#群管更新` | 仅主人私聊；操作日志最近 20 条 |

`@成员` 可按原规则换为数字 QQ。禁言、解禁还保留 `禁言 @成员 [时长]`、`解禁 @成员`、`#禁言`、`/禁言`、`#解禁`、`/解禁`。时长支持数字、中文数字及秒、分、分钟、时、小时、天；纯数字按分钟，默认 10 分钟，范围 1 秒至 30 天。

裸 `撤回` 必须带有效群消息引用；无引用、私聊或“撤回一下”等正文不执行。裸 `赞我` 必须整条正文精确匹配，“快来赞我”不触发。其他功能不因此支持裸词。

## 功能说明

- **成员管理与撤回**：核验操作人、机器人和目标的实际权限。批量撤回使用插件记录的近期消息，默认最多 20 条、10 分钟内，可在配置中调整。
- **申请审核**：成员申请按群设置，机器人入群邀请按全局设置。可以自动处理、答案匹配，或通知管理群、指定用户人工审核。
- **欢迎与退群**：欢迎和离群通知可以分别开启。自动退群默认关闭，按名单、人数和主人等豁免条件判断。
- **发言榜**：按机器人和群统计发言、图片数量，提供今日、昨日和月榜。
- **每日新闻**：每个群可以配置自己的接口和鉴权，支持手动查询与定时推送；停机错过的内容不补发。
- **点赞**：在群里发送“赞我”，每次提交 10 赞。每个机器人每天最多提交 100 赞，同一人当天只提交一次，所有群共用额度；到账数量由平台决定。

`#群管状态` 默认发送图片，渲染失败时返回文字；`#群管状态 文字` 可以直接看文字版。帮助图随版本提供，主人私聊时会附加维护说明，群里显示公开帮助。

完整字段、审核规则、额度和数据保存方式见 [功能与配置说明](docs/FEATURES.md)。

## 更新

在插件目录执行：

```sh
git pull --ff-only origin main
```

或由主人私聊发送 `#群管更新`。更新完成后按平时方式重启机器人。已有源码改动或分支冲突时，更新会停止并提示处理。

ZIP 安装请下载新版后替换源码，保留 `config/local.json`、`data/` 和其他实例配置。升级前建议备份这两处；`data/` 中有统计、审核、点赞额度和网页密码，不要当缓存删除。

## 其他框架接入

`api.mjs` 提供统一的事件输入和操作回调，图片生成也可以交给宿主框架。适配完成后使用该框架即可，无需安装 TRSS。适配层负责订阅消息、转换事件和调用宿主操作，群管继续处理业务规则与权限。

接入约定见 [适配文档](docs/ADAPTERS.md)，模板见 [framework-adapter.mjs](examples/framework-adapter.mjs)。目前随包提供 TRSS 适配，其他框架以后按需补充。
